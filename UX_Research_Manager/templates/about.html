About UX Research Manager

What is UX Research Manager?

UX Research Manager is a tool designed to help UX designers and researchers organize, store, and analyze research insights in one place.

Core Features

  • 📝 Create and manage research insights
  • 👥 Define and link personas
  • 🗺️ Map insights to user journey stages
  • 🤖 AI-powered research summarization
  • 💾 Persistent data storage

Technology Stack

Built with Python, Flask, and powered by Mistral AI
